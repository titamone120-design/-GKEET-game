# GKEET — Shadow Arena

A standalone mobile-first fighting game. This repository is separate from IMSIYA.

## Play
Open `www/index.html` in a modern browser, or serve the repository with any static web server.

## Controls
- Mobile: on-screen left/right, jump, punch, kick, special.
- Keyboard: A/D or arrows to move, W/Up/Space to jump, J punch, K kick, L special, Escape pause.

## Features
- 20 progressively harder rivals.
- Health bars, fight timer, hit effects, knockback and enemy AI.
- Stage unlocks and victory records saved on the device.
- Difficulty selection and responsive touch controls.

## Android APK
Every push to `main` starts the **Build GKEET Android APK** workflow. When it succeeds, open the workflow run on GitHub and download the `GKEET-Android-APK` artifact.
